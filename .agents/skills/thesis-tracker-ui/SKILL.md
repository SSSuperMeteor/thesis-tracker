# thesis-tracker 界面设计

与通用技能 frontend-design 冲突时,以本文件为准。frontend-design 用来检查成品有没有滑向"模板化默认",本文件决定具体怎么做。

## 产品与受众

- 一个人在自己电脑上用的研究工作台。Windows + Chrome,中文界面,只在本机打开。
- 三件核心事:看数据库里有什么;读建议卡并追溯每个数字的来源;手动发起分析并看进度。另有按公司对话。
- 气质:冷静、克制,像排版认真的研究笔记本,不像交易 App。数字是主角,不靠装饰撑场面。
- 不是营销页。不要 hero 大标题、不要渐变、不要插画、不要 emoji。

## 记忆点:论点与证据并排

建议卡详情页分两栏:左栏是阅读栏(结论、价格图、理由、失效条件),右栏是证据面板(事实表,吸顶)。聊天页用同一个布局。

- 理由和说明文字里的每个事实数字是一个"事实标记":1px 虚线下划线,强调色。悬停显示来源(工具、日期、fact_id);点击后右栏对应行高亮约 1.2 秒并滚入视野。派生出来的数字(`compare_facts` 的结果)用实线下划线,悬停显示"计算结果｜公式与来源编号",证据行带"计算结果"标签。
- 这是全站唯一的强调手法。其余地方保持安静。
- 前端不解析数字。后端以片段数组提供正文:`{"type":"text","value":"…"}` 与 `{"type":"fact","fact_id":"…","display":"333.69 美元/股"}`。前端只负责把片段渲染成文本和事实标记。

## 设计令牌

先把这些写成 CSS 变量,所有颜色、间距、圆角都引用变量,页面里不出现裸色值(`app.css` 的令牌块是唯一允许写十六进制色值的地方,有测试扫描)。

```css
:root {
  color-scheme: light dark;
  --paper: #F7F9FA;      /* 内容区:带一点冷调的白 */
  --surface: #FFFFFF;    /* 面板 */
  --surface-2: #EEF2F4;  /* 悬停、安静的填充 */
  --ink: #17212B;
  --ink-2: #4A5763;      /* 辅助文字,不得再引入更浅的文字色 */
  --rule: #DCE3E8;       /* 发丝线:结构,不是边界 */
  --ctl-rule: #77828C;   /* 按钮、输入框轮廓,任何底色上 ≥ 3:1 */
  --accent: #0B5F6C;     /* 链接、选中、焦点、事实标记、10-K 色块 */
  --accent-1: #EEF6F8;   /* 强调色三档浅色:最浅,当前季度列、行悬停 */
  --accent-2: #D6E9EC;   /* 中,10-Q 色块、徽标底色、选中的范围 */
  --accent-3: #B3D5DB;   /* 最深,色块悬停 */
  --accent-soft: #D6E9EC;/* 事实标记点击后闪的底色 */
  --on-accent: #FFFFFF;  /* 实心强调色块上的字(深色主题里是近黑) */
  --ok: #1F6B4A; --warn: #8A5008; --bad: #A62F24;
  --none: #717C85;       /* 斜线纹理与空心"缺失"标记;不用于文字 */
  --side-bg: #111B24;    /* 侧栏:两种主题下都是深色 */
  --side-ink: #E8EEF2; --side-ink-2: #9FB0BD; --side-rule: #243441;
  --side-active: #1E2D3A; --side-accent: #6FC0CF; --side-warn: #E0A64E;
}
/* 深色主题在 @media (prefers-color-scheme: dark) 里覆盖同样的名字 */
```

- 不用红绿表示涨跌。A 股和美股的红绿约定相反,色盲也分不清,所以涨跌只用符号(+ / −)和文字,不上色;走势线用墨色,终点用强调色圆点。
- 状态永远是"文字加形状",不靠颜色单独表达:正常(实心点加文字)、过期(时钟图标加文字,警告色)、出错(叉号加文字)、运行中(缺口圆环加文字)、缺失(空心虚线框)。倾向与动作徽标也是形状加文字(▲ 看多、■ 中性、▼ 看空)。
- **阴影**:只有两处——面板上一层 `0 1px 2px`、透明度 0.06,以及对话框。不用渐变(含 `linear-gradient` 做斜线纹理:斜线用 SVG `<pattern>`)。
- 圆角分级:单元格与色块 3px,控件 4px,面板和对话框 8px。不要所有东西同一个圆角。
- 每新增一个文字与背景的组合,必须同时加进 `tests/test_webapp_design_tokens.py` 的配对表(浅色与深色两套都要过)。

## 字体与排版

- 字体栈只用系统字体,不下载网络字体(本机、离线也要能用):
  `"Segoe UI Variable Text","Segoe UI","Microsoft YaHei UI","PingFang SC","Noto Sans CJK SC",system-ui,sans-serif`
- 字号阶梯:11(时间线日期)/ 12 / 13 / 14(正文)/ 15(面板标题)/ 18(大徽标)/ 22(指标数字)/ 24(页面标题)。字重只用 400 和 600。中文标题不要 700。
- 行高:阅读文字 1.65–1.7,表格 1.4。字距保持 0。
- 阅读栏宽度上限约 38 个汉字;表格不受此限。
- 所有数字列用 `font-variant-numeric: tabular-nums`,表格中数字右对齐,单位跟在数字后面,字号小一级、颜色 `--ink-2`;指标块里单位在数字下一行。
- 标题和标签用句式大小写,不用全大写,不在标题上方加小标签,不在按钮文字后加 "→"。

## 布局

```
┌──────────────┬──────────────────────────────────────────────┐
│ ▢ Thesis     │ 页面标题 24/600                     [主操作] │
│   Tracker    │ 说明行(次要色),用间距分隔,不画通栏线        │
│ ▦ 总览       │ ┌ 面板 ─────────────────────────────────────┐ │
│ ▤ 建议卡     │ │ 面板标题 15/600  [计数]            [操作] │ │
│ ≡ 任务    ●1 │ └───────────────────────────────────────────┘ │
│ ──────────── │                                              │
│ ● 价格有效   │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- 左侧是深墨色侧栏,232px,吸顶;顶部字标加 SVG 标记,导航项带线性图标(内联 `sprite.svg`,不引外部库),当前项左侧强调色竖条加浅底。窗口窄于 900px 时变成顶部栏。
- **价格状态胶囊**常驻侧栏底部(取代页面顶部的提示条):写最新价格日与落后天数;过期用警告色加时钟图标加文字;点击展开 `uv run prices-ingest` 与"复制命令"。界面不执行任何命令。
- 页头:标题 24px/600,下一行次要色说明,右侧是主操作;用间距分隔,不画整页分隔线。
- 面板:白色表面、1px 边线、8px 圆角、内边距 20px;标题 15px/600,可带计数小标。不用渐变、不用大面积彩色填充。
- 总览:色块矩阵,首列(公司)左侧吸附,表头吸顶,右侧五列汇总吸附(1200px 以下不吸附),横向可滚动,打开时滚到最新季度。
- 公司页:页头(最新价与日期、数据范围)、价格走势图、财报时间线、可算的财务指标(指标块网格)、建议卡(紧凑卡片)、对话。
- 建议卡详情:两栏。窄屏(<1099px)时证据面板移到正文下方,不再吸顶。
- 聊天:消息区在限宽阅读栏里,输入区固定在栏底部,用量以小号次要色一行显示。
- 每个"一栏"的网格都写 `grid-template-columns: minmax(0, 1fr)`:隐式列和最宽的内容一样宽,一个长编号就会撑出视口。
- 对齐:正文左对齐;数字列右对齐;不使用居中和两端对齐。

## 组件规则

覆盖矩阵
- 行是公司,列按"财期截止日所在的日历季度"分组。不同公司财年不同,界面和文案里不得出现"第几财季",只显示真实的财期截止日。
- 色块:**10-K 实心强调色块配 K,10-Q 浅强调底配 Q**,修订申报在色块角上加一个圆点,**真实空洞用斜线纹理加虚线边**。同一格有多份申报时并排画出。悬停显示表单、财期截止日、披露日、accession。
- **斜线只有一个意思**:同一公司相邻两份财报间隔超过 135 天时,中间没有财报的季度。没披露的季度留白。
- **当前季度整列淡底**(`--accent-1`),即使还没有人披露也有这一列;悬停高亮整行整列。
- 年份只在每年第一列的表头写一次,季度字母小号;每年之间用 1px 竖线分隔。
- 汇总列:最新价(数字右对齐)、近半年走势、价格数据范围、最新价格日、建议卡数量。

走势迷你图
- 后端给归一化路径;墨色折线,终点强调色圆点;涨跌不用红绿;没有足够价格时显示"—"。

价格图(公司页与卡详情页)
- SVG 折线;**后端提供下采样序列、折线路径、百分比坐标、坐标轴标签字符串、悬停用的逐点日期与价格字符串**,前端只摆放,不计算价格,不格式化数字。
- 画复权收盘价,叠加 50 日、200 日均线(线型不同:实线强调色、虚线次要色);**历史不足时不画对应均线并说明**。
- 卡详情页另画买点区间(横带)、止损(点线)与目标(长虚线)、建卡当天收盘价标记;标签文字与位置由后端给出,任何价格量级下标签不重叠;**没有价位的动作不画价位线**并说明。价位只在图里画一次,不再有单独的价位带。
- 范围切换 3 个月 / 1 年 / 5 年(三个 `aria-pressed` 按钮,三份数据都在响应里);悬停十字线显示日期与收盘价;图可聚焦,左右方向键逐日移动,读数写入 `aria-live`。窄屏只保留第一、中间、最后三个日期标签。

结论条与指标块(卡详情)
- 顶部结论条:倾向与动作做成大号徽标(形状加文字),旁边是周期与置信度(标"未校准");下面一排四个指标块(买点区间、止损、目标、盈亏比),大号数字加小号单位。没有的值写"无",用安静的样式。

数据表
- 行高 36–40px;表头小号次要色;悬停整行浅底;数字列 tabular-nums 右对齐;不用斑马纹;行末"查看"是箭头图标按钮,带 `aria-label`。

按钮与对话框
- 每个视图最多一个主按钮(实心强调色),其余用描边按钮。
- 会花钱的操作必须弹确认框:写明"将调用 DeepSeek 并按量计费",并显示后端提供的最近几次分析平均用量。不要在前端写死任何金额或 token 数。
- 动作命名全程一致:按钮"生成建议卡",进度"正在生成建议卡",完成提示"建议卡已生成"。
- 复制成功用轻量提示:2 秒自动消失,`aria-live="polite"`。

空状态、加载占位、错误
- 同一个组件(`.notice`)的三种语气:空状态是行动入口("还没有这家公司的建议卡。选择周期后点击生成建议卡。");加载是静态灰块;错误说清发生了什么和怎么处理,不道歉。

任务进度
- 时间线样式:每步一个圆点、类型、说明、时间;运行中显示安静的状态指示(缺口圆环加文字),不做假进度条;新步骤追加进同一个列表(`aria-live="polite"`),不整体重建。

聊天
- 用户消息是浅底块,回答是正文,没有气泡、没有渐变;被拒回答只显示违规报告、永不显示草稿;提议是带边线的卡片,处理过的留成一行状态;回合进行时输入区禁用并写明在等什么。

## 数字与来源(硬性规则)

- 前端不计算、不四舍五入、不拼单位。所有金融数字和标签都是后端给的字符串,前端原样渲染。
- 前端代码里不得出现 `toFixed`、`toLocaleString`、`Intl.NumberFormat`、`Number(`、百分比乘除等数字格式化逻辑,也不得硬编码金融数字(含 SVG 的几何数字:路径与坐标来自后端或样式表)。有测试扫描这一点,覆盖所有 `.js`、`.html`、`.css`。
- 唯一允许的算术是数个数,以及按方向键时在点列表里前后移一格。
- 公司代码和 fact_id 加 `translate="no"`。
- 日期原样显示后端字符串;时间戳一律由后端格式化为本机时区的 `YYYY-MM-DD HH:MM`。

## 状态与文案

- 拒绝的草稿要展示违规规则编号和大白话说明,不隐藏。
- 每张卡底部固定显示免责声明(由后端提供原文,不得删改),并安静地列出提示词版本和校验器版本。
- 语气:中文、平实动词、不用感叹号、不写营销词。

## 动效

- 只有:事实标记点击后的高亮、对话框打开、任务状态变化时的文字更新,以及用户点击触发的价格胶囊箭头翻转。
- 不做进入动画、不做悬停上浮、不做滚动视差。
- 尊重 `prefers-reduced-motion`:开启时高亮改为静态底色,胶囊箭头不再过渡。
- 只对 `transform` 和 `opacity` 做过渡,不写 `transition: all`。

## 无障碍与质量底线

- 用语义元素:`button` 做操作,`a` 做跳转,`table` 加 `th scope`,不用带点击事件的 `div`。
- 所有交互元素有可见焦点:`:focus-visible`,2px 强调色环,偏移 2px(侧栏里用侧栏强调色)。不写没有替代的 `outline: none`。
- `<html lang="zh-CN">`,提供跳到主内容的链接,标题层级连续;导航到新页面后焦点移到该页的 `h1`。
- 图标按钮要有 `aria-label`;装饰图标 `aria-hidden="true"`。
- 文字对比度 ≥ 4.5:1,控件边界和焦点环 ≥ 3:1,由 `test_webapp_design_tokens.py` 读取令牌断言,浅色和深色两套都要过。
- 页面宽度从 360px 到 1920px、浏览器缩放到 150% 都不出现整页横向滚动;宽表格在自己的容器里滚动;长而无空格的文字换行而不是撑宽。
- 不加载任何外部资源(无 CDN、无网络字体、无统计脚本);响应头设置 `Content-Security-Policy: default-src 'self'`。不用 `position: fixed`(吸附用 `sticky`)。
- 吸顶元素只有:总览表头与公司列与汇总列、证据面板、侧栏、聊天输入区、复制提示。每增加一个都要在 `test_webapp_responsive.py` 的精确集合里点名。

## 验证

- **浏览器端到端测试是验收的一部分**:`tests/test_e2e_*.py` 用 Playwright 驱动真实页面(假模型客户端只在测试代码里注入,不新增命令行开关或环境变量)。改前端先写会变红的端到端测试。
- 视觉自查:在 1440×900 与 390×844、浅色与深色下对总览、公司页、卡详情、任务页、聊天页截图并逐张看;`scripts/webapp_layout_check.mjs` 做两栏间距、日期换行、整页溢出、价位标签重叠的量化断言。截图放在仓库之外。没有无头浏览器就如实标注"视觉未验证",不要自行安装系统级软件。

## 交付前自查

- 回看设计令牌:是否滑向通用默认(米色加陶土色、近黑加荧光绿、满屏圆角卡片加灰阴影、满处大写小标签)。如果有,改掉并在报告里说明。
- 借香奈儿的话:出门前照镜子,摘掉一件配饰。找出一个纯装饰、不承载信息的元素并删掉(第四轮删掉的是每个页面标题下的整页分隔线,以及与图表重复的价位带)。
- 同一个信息只画一次;同一个数字在每个页面读起来一样(都来自后端的同一个显示函数)。

## 第四轮对本文件的改动(与原规则冲突处以此为准)

| 原规则 | 现规则 | 原因 |
|---|---|---|
| 布局是 200px 左侧导航、白底、仅文字 | 232px 深墨色侧栏,字标加 SVG 标记,线性图标,当前项竖条;价格状态胶囊常驻底部 | 层级单一、侧栏只有文字;过期提示条占据每页顶部 |
| 价格过期提示是页面顶部的提示条 | 侧栏胶囊,点击展开命令 | 同上;状态应该常驻而不是每页重复 |
| 阴影只用于对话框 | 面板可有一层 `0 1px 2px`、透明度 0.06;对话框不变 | 面板需要和白色内容区拉开层次,又不能回到"灰阴影卡片" |
| 字号 12/13/14/16/20/28 | 11/12/13/14/15/18/22/24 | 页标题 24、面板标题 15、指标数字 22、大徽标 18 形成清晰层级 |
| 单元格 24×24,K / Q 字母,缺失是虚线空框 | 色块:10-K 实心、10-Q 浅底、修订圆点、空洞斜线纹理;当前季度列淡底;悬停整行整列;每行加最新价与走势 | 总览"只有字母",读不出年报与季报 |
| 价位带 | 价格图(含买点区间、止损、目标、收盘价标记),价位只画一次 | 详情页以文字为主;价位带与图表是同一信息 |
| 详情页顶部是倾向与动作两行文字 | 结论条:大号徽标、周期、置信度,下接四个指标块 | 同上 |
| 面板标题、表格是默认样式 | 面板标题带计数;表格行高 36–40px、悬停整行、箭头图标按钮 | 表格像默认样式 |
| 任务进度是带分隔线的逐行文字 | 时间线,新步骤原地追加 | 任务页大片空白;避免整体重绘导致重复朗读 |
| 强调色一档(`--accent-soft`) | 强调色四档(实心加三档浅色)与 `--on-accent`,侧栏令牌七个 | 色块、徽标和当前季度列需要不同强度的底色 |
| 动效只有三处 | 加一处用户点击触发的胶囊箭头翻转 | 展开状态需要被看见;仍只动 `transform` |
| 不写"没有 position: fixed"的约束 | 明确写出不用 `position: fixed`,吸附用 `sticky` | 既有测试一直在守这一条,现在写进规则 |
