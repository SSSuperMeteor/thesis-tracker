# 本机网页工作台审计（第四轮）

本文记录对 `uv run webapp` 的一次系统检修：怎么查、查到什么、根因、怎么修、
怎么证明修好。**已定 / 待定**写在每节里。截图在仓库之外（`~/reports/webapp-shots/`，
不提交）。真实模型验证的原始数据在 `~/reports/real-chat-run.json`。

## 1. 方法

1. 基线：`git status` 干净、无 stash；`pytest` 1111 通过。
2. 用环境里已有的 Playwright + Chromium（Node 版，没有安装任何东西），在真实本地数据
   （15 家公司、12 张卡）上逐路由、逐接口走一遍，抓控制台报错、4xx/5xx、请求失败、
   页面异常、溢出和截断。审计用的服务是 `--no-worker`，并使用独立的任务/聊天库，
   所以审计过程不会触发任何付费调用。
3. 先建清单、再动手；每个 bug 先写能复现的测试（优先端到端），看着它变红，再修，再变绿。
4. 端到端框架：`tests/e2e/*.mjs`（Playwright 脚本）+ `tests/e2e_support.py`。pytest 启动真实服务，
   **假模型客户端只在测试代码里注入**（`server.CLIENT_FACTORY` 的猴子补丁，没有新增任何
   命令行开关或环境变量）；缺 Node / Playwright / Chromium 时测试是**跳过**并写明原因，
   不会假装通过。

## 3. 清单上"已知需核实"的几项

### 3.1 任务页进度第一行的用量

新格式任务的第一行是"准备：读取本地数据 N 次"（没有用量，因为还没有模型请求）；第二行起的
"第 N 轮"带本轮与累计用量，数字取自 `round` 事件（模型响应之后才发出）。真实任务
`94d2e051…` 实测：第 1 轮"本轮输入 10721｜输出 2763｜累计输入 10721"，第 2 轮累计 31734，
与结果区的 31734 一致。旧任务里的 `round_start` 事件按"第 N 轮（旧记录，没有用量）"渲染，不再显示
虚假的 0。**结论：分析任务没有问题**；聊天任务有问题，见 A-07。

### 3.2 总览虚线空框规则

规则：只在同一公司**相邻**两份财报间隔超过 135 天时，才对中间的空季度画虚线框。

- 用独立算法（按公司排序期末日、找相邻间隔 > 135 天、再看中间有没有空季度）对真实库的 15 家公司
  逐家重算，与接口的 `dashed_quarters` **0 处不符**（目前没有任何公司触发）。
- 合成数据发现一个边界错误（A-09）并已修复。
- 真实数据里的空格（SNDK 2025Q3；LITE 2016Q1、2017Q1、2021Q1、2023Q1）是财年切换造成的，
  相邻财报间隔都不超过 135 天，所以保持空白而不是虚线——与规则一致。

## 4. 一致性、安全与显示

- **同一个数字**：公司页"最新收盘价"、总览"最新价"、卡详情的收盘价、聊天证据里的收盘价都来自同一个
  `display_text`；真实数据上 NVDA 233.95 美元/股在四处一致；聊天里的"差值 15.83、7.26%"与卡自己的
  自动计算逐位对得上。时间格式全页统一为本机时区的 `YYYY-MM-DD HH:MM`（A-11 是唯一例外，已修）。
  端到端测试对每个页面扫描 `undefined`、`NaN`、ISO 时间戳、内部编号与英文原因码，全部为空。
- **安全**：令牌不进日志（`log_message` 空实现，既有测试仍通过）；Host / Origin / POST-only 既有 34 个
  安全测试全过；新增 `/api/price-status` 同样需要令牌（有测试）；没有任何响应包含哨兵密钥。
  `/api/balance` 的 key 仍只在服务端使用。唯一的安全相关缺陷是 A-21（413 被重置），已修。
- **缩放 125%/150%/200%**（等效 CSS 宽度 1152/960/720）：四个页面都没有整页横向溢出（测试覆盖前两档）。
- **悬停提示被截断**：提示是浏览器原生 `title`，不会被页面容器截断；图表提示有左右翻转，后端测试断言
  靠近右缘的点 `align` 为 `end`（提示向左展开）。
- **吸顶遮挡**：点事实标记后目标行滚入视口中央（实测 1152/960/720 宽度下行都在可见区内）。
