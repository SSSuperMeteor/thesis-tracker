# Thesis Tracker — Stock Research AI Agent

Thesis Tracker is a local-first foundation for evidence-based stock research.

```text
Ticker
→ Financial/News/Market Data
→ Retrieval
→ Verified Evidence
→ Playbook Analysis
→ Agent Orchestration
→ Evaluation
→ Optional Decision Mode
```

## Core principles

> Python handles state, math, deterministic computation and validation.
> LLMs handle unstructured semantic extraction, planning and judgments that cannot be reliably rule-based.

> Agent autonomy does not mean unrestricted LLM behavior. All actions must pass through controlled tools, state and validators.
